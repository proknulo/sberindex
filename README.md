# Типы локальных экономик России: кластеризация муниципалитетов на динамической атрибутированной сети

Решение номинации «Кластеризация» онлайн-конкурса СберИндекса (2026).

**Что сделано.** Для 1815 муниципальных образований (МО) и 24 месяцев (январь 2023 — декабрь 2024)
построена динамическая атрибутированная сеть. Атрибуты МО — уровень и структура безналичных
трат жителей (СберИндекс), сезонность трат, отраслевая структура занятости и зарплаты
(БДПМО Росстата), доступность рынков и население. Каждый месяц МО связывается с 15
экономически ближайшими МО, так что сеть перестраивается вместе с экономикой.

**Результат.** 8 типов локальных экономик: столичные пригороды, удалённый Северо-Восток,
ресурсные и вахтовые центры, крупные города, города и районы Сибири и Дальнего Востока,
индустриальные малые и средние города, сельская периферия Сибири, аграрная глубинка.
Итоговая модель — эволюционная спектральная кластеризация (PCQ) на kNN-графе атрибутов.
Она выбрана из 9 методов и 7 правил построения рёбер по шести ICVI (SW, CH, S_Dbw, AVI, AVU,
MQ), стабильности во времени и устойчивости к подвыборке. 71% МО не меняют тип за два года,
91% переходов идут между соседними типами. Выделены сезонные сдвиги и тренды:
сокращение индустриального типа, рост маркетплейсов, растущий разрыв в тратах.

## Быстрый старт

Нужны Python ≥ 3.11 и `bsdtar` (есть в macOS; в Linux — пакет `libarchive-tools`).

```bash
make setup      # виртуальное окружение и зависимости
make data       # данные СберИндекса + справочник МО + выгрузка БДПМО Росстата (~30 мин, кэшируется)
make run        # пайплайн: признаки → графы → сравнение → итоговая модель (~10 мин)
make report     # рисунки для отчёта
make landing    # landing/data.js для интерактивного лендинга
```

Проверки надёжности (чувствительность к весам и гиперпараметрам, пространственная валидация):
`.venv/bin/python -m sbx.robustness`. Внутригородская структура столиц: `.venv/bin/python -m sbx.intracity`.
Тесты индексов качества: `.venv/bin/python -m pytest tests`.

Лендинг открывается локально: `python3 -m http.server --directory landing`, затем http://localhost:8000.

Все случайные процессы зафиксированы `seed` из конфигурации; повторный запуск даёт те же результаты.

## Структура

```
configs/            гиперпараметры (YAML) и интерпретация кластеров
scripts/
  get_data.py       открытые данные СберИндекса и справочник МО
  download_rosstat.py  выгрузка показателей БДПМО Росстата по всем регионам
src/sbx/
  data.py           загрузка и согласование источников по territory_id
  features.py       пространство атрибутов (блоки, CLR, веса, импутация)
  graphs.py         7 правил построения рёбер
  clustering.py     K-means, Ward, спектральная, Leiden, AGC, темпоральный Leiden
  validity.py       ICVI: SW, CH, S_Dbw, AVI, AVU, MQ, модулярность
  dynamics.py       эволюционная кластеризация, события, метрики динамики
  pipeline.py       весь анализ
  robustness.py     проверки устойчивости
  intracity.py      отдельный анализ внутригородских территорий Москвы и Санкт-Петербурга
  viz.py, figures.py  рисунки; geo.py, landing.py — данные для лендинга
landing/            интерактивный лендинг (index.html + data.js)
docs/report.md      методологический отчёт
results/            таблицы и рисунки
tests/              тесты индексов качества на графах с известным ответом
```
