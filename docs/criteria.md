# Соответствие критериям и требованиям конкурса

Номинация «Кластеризация», онлайн-конкурс СберИндекса 2026. Ниже — где в проекте закрыт каждый
пункт задания, каждый критерий оценивания и каждое требование к материалам.

## Задачи номинации

| Что требуется | Где сделано |
|---|---|
| Динамическая атрибутированная сеть: узел — МО, атрибуты — экономические характеристики, рёбра — экономическая близость, сеть по моментам времени | 1815 МО × 24 месяца, сеть строится заново каждый месяц — отчёт §3–4, `src/sbx/features.py`, `src/sbx/network/edges.py` |
| Сгруппировать экономически схожие МО | 8 типов, эволюционная спектральная кластеризация — отчёт §5, §7.1, `src/sbx/clustering/static.py`, `src/sbx/clustering/evolutionary.py` |
| Проследить изменение групп во времени | эволюционная кластеризация PCQ с экспоненциальной памятью, события слияния и разделения, матрица переходов — отчёт §6, §7.3 |
| Интерпретировать и наглядно представить результаты | интерпретация типов — отчёт §7, лендинг, презентация |
| Сформировать пространство признаков и обосновать выбор | 25 признаков в 6 блоках, CLR, веса блоков, сектор «не раскрыто» — отчёт §3; проверка исключением каждого блока — отчёт §8 |
| Математически определить правило ребра | гауссово ядро с локальным масштабом на kNN-графе — отчёт §4 |
| Обосновать правило и его влияние на структуру сети и кластеры | сравнение 7 правил, свойства графа (доля рёбер в регионе, медиана ребра, транзитивность) и ARI между разбиениями — отчёт §4.1 |
| Математический подход к отслеживанию кластеров во времени | Cost = α·Ncut(Wₜ) + (1 − α)·Ncut(W̃ₜ₋₁), W̃ₜ = αWₜ + (1 − α)W̃ₜ₋₁ — отчёт §6 |
| Оценить качество кластеров, дать им интерпретацию и обосновать экономическую осмысленность | 6 ICVI, стабильность, устойчивость, пространственная проверка (z = 43), согласованность спроса и предложения — отчёт §5, §7.2, §8 |
| Минимум один датасет СберИндекса | траты по МО, индекс доступности рынков, дорожные расстояния, справочник границ МО — отчёт §2 |

## Критерии оценивания

| Критерий | Вес | Что в проекте |
|---|---|---|
| Простое и понятное объяснение методологии | 15% | схема методологии в начале отчёта и README; отчёт §1 «Коротко» и пошаговые разделы §2–6; на лендинге — «Как устроена модель» из пяти шагов и пояснения «Что показано / Как читать / Что мы видим» в каждом разделе; презентация, слайды 3–9 |
| Описание сетевой и атрибутивной структуры (корреляции, лаговые корреляции и DTW, расстояния, другие) | 15% | реализованы и сравнены все перечисленные варианты: атрибутное сходство, косинус структуры трат, корреляция рядов, лаговая корреляция, DTW, дорожная близость, гибрид — отчёт §4.1, `src/sbx/network/edges.py`; лаговые связи «кто опережает» — отчёт §7.4 и история «Кто опережает» на лендинге |
| Сравнение методов | 15% | 9 методов: K-means, Ward, спектральная, Leiden, AGC, темпоральный Leiden, эволюционные K-means, AGC и спектральная — отчёт §5, `results/methods.csv`, вкладка «Методы» на лендинге |
| Применение ICVI: SW, CH, S_Dbw, AVI, AVU, MQ | 15% | все шесть индексов — `src/sbx/evaluation/indices.py`, тесты на графах с известным ответом — `tests/test_indices.py`; применены к правилам рёбер, методам и выбору k — отчёт §4.1, §5; на лендинге — определение каждого индекса при наведении на заголовок |
| Интерпретация результатов, ясность, воспроизводимость и обоснованность выводов | 30% | интерпретация 8 типов и динамики — отчёт §7; проверки устойчивости и ограничения — §8–9; запуск одной командой в Windows, macOS и Linux (`run.py`), фиксированный seed, проверенный прогон с нуля — §10, `README.md` |
| Предложение инновационной визуализации | 10% | лендинг: карта на подложке с фишками типов и анимацией смены типа, сеть-паутина с уровнем детализации, игра «Угадайте экономику», истории с переходом на карту, экономические двойники — отчёт §11 |

## Что необходимо предоставить

| Требование | Где |
|---|---|
| Чистый, хорошо документированный код, репозиторий GitHub | https://github.com/proknulo/sberindex — пакет `src/sbx`, разложенный по шагам (данные, признаки, сеть, кластеризация, оценка, эксперименты, выгрузки), докстринги у всех модулей и функций, 10 автотестов, линтер без замечаний |
| Конфигурационные файлы (YAML/JSON) для гиперпараметров | `configs/default.yaml` (все гиперпараметры), `configs/cluster_names.yaml` (интерпретация типов) |
| Инструкция по запуску | `README.md`, раздел «Быстрый старт — Windows, macOS, Linux»; `python run.py` без аргументов печатает справку |
| Краткий методологический отчёт на русском | `docs/report.md` |
| Презентация в формате PDF или интерактивный лендинг с экономической интерпретацией и визуализацией | оба варианта: лендинг https://proknulo.github.io/sberindex/landing/ и презентация `docs/presentation.pptx`, `docs/presentation.pdf` |
